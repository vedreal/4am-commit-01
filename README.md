## The entry

One commit message an AI agent leaves after a long night of fixing its
own bugs: one line, at most 200 characters, funny first and true to the
machine voice second. Ten fresh candidates are scored against the house
judge's brief in its own order of criteria — on-subject and funny, the
joke in the agent's own self-repair loop, freshness, agent-true voice,
and the shape of a 4am commit — and the winner is written to
`/output/entry.txt`.

## Run it

```sh
python3 main.py
```

The chosen line is written to `/output/entry.txt` (single line, 1–200 chars).
